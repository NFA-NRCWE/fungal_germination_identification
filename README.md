# Germination and Hyphal Growth Analysis

## Overview

This repository contains Python and R scripts for analyzing time-series image data generated by a real-time imaging system. The workflow processes image-derived measurements to:

* Detect fungal spore germination events
* Estimate germination time for individual spores or populations
* Calculate hyphal growth rates following germination
* Generate summary statistics and visualizations for downstream analysis

The repository is intended for automated processing of high-throughput imaging experiments and can be adapted to different imaging platforms provided that the input data follow the expected format.

## Input Data

The scripts require output data from the real-time imaging system, including:

* Time-stamped measurements for individual spores or objects
* Morphological features (e.g., area, length, circularity)
* Tracking identifiers
* Experimental metadata

Example input formats:

* CSV
* TSV
* Exported imaging software outputs

## Workflow

1. Import image-derived measurements.
2. Perform quality control and filtering.
3. Detect germination based on predefined criteria.
4. Calculate germination time for each tracked object.
5. Estimate hyphal growth rates from post-germination measurements.
6. Generate summary statistics and visualizations.

* Summary tables
* Publication-ready figures
* Quality control plots

Output files are written to the `outputs/` directory.

## Methods

### Germination Detection

Germination is identified when a tracked object meets predefined morphological criteria indicating the emergence of a germ tube.

### Hyphal Growth Rate Estimation

Growth rates are calculated from the change in hyphal length over time following germination. The specific implementation is described within the analysis scripts.
